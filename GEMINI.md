# Project Overview

This is a personal website project built with React and Vite. It showcases a portfolio with sections for landing, about, experience, projects, and contact. The styling is done using SCSS, and it uses the AOS library for animations.

## Building and Running

### Prerequisites

- Node.js and npm (or yarn)

### Installation

```bash
npm install
```

### Development

To run the development server:

```bash
npm run dev
```

### Build

To build the project for production:

```bash
npm run build
```

### Preview

To preview the production build:

```bash
npm run preview
```

## Development Conventions

- The project uses React components with JSX.
- Styling is done with SCSS, with separate files for each component.
- The project is structured with a `src` directory containing components, static assets, and styles.
- The main application component is `App.jsx`, which assembles the different sections of the website.
